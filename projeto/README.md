# Combo Tactics

![Combo Tactics Logo](en/imagens/logo.png)

A turn-based tactical RPG for the browser. The player manages a team of 3 fighters (Fire, Water or Plant; Warrior, Mage or Tank) in 1v1 arena duels, with a casino-style arena draw every 3 rounds.

- **Engine:** Unity (WebGL), no installation required
- **Modes:** Campaign (4 stages), vs AI, local PvP
- **Target release:** November 2026
